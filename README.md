\# TutorialNinja Simple Selenium Project



This is a beginner Selenium WebDriver automation project using Java.



\## Website

https://tutorialsninja.com/demo/



\## Covered Scenarios

\- Sign Up / Register

\- Login

\- Search

\- Add to Wishlist

\- Add to Cart

\- Change Currency



\## Tools Used

\- Java

\- Selenium WebDriver

\- ChromeDriver

\- WebDriverManager

\- Maven



\## Main Selenium Commands Used

\- get()

\- findElement()

\- By.id()

\- By.name()

\- By.cssSelector()

\- By.linkText()

\- By.partialLinkText()

\- sendKeys()

\- click()

\- clear()

\- getPageSource()

\- quit()



\## How to Run

1\. Open the project in IntelliJ IDEA.

2\. Open `src/main/java/org/example/Main.java`.

3\. Run the `main` method.
